# 人身保险产品基础知识问答 Agent

🍅 西红精算 · 基于《人身保险产品基础知识问答手册》（保监寿险〔2008〕1640号）的检索增强问答应用。

在线地址：https://xihongactuary.github.io/life-insurance-qa-agent/

## 它做什么

1. **先检索**：本地对 77 条手册原文做中文 bigram + IDF 检索（带口语→书面语同义词扩展），取最相关条目；
2. **再作答**：把命中条目作为参考资料交给大模型，按「只依据资料、说人话、不推销」的规则作答并流式输出；
3. **可溯源**：回答下方列出命中的手册条目原文与「口径更新」标注，点开即看；
4. **能降级**：用户未配置 API Key 时，直接返回知识库原文命中结果，功能不中断。

## 接入大模型

页面右上角「⚙ 模型设置」填入任意 **OpenAI 兼容**接口即可（Base URL / API Key / 模型名），密钥只存在浏览器 localStorage，不上传、不落库。

内置预设：DeepSeek、硅基流动、智谱 GLM、Moonshot、通义千问、本地 Ollama。

> 静态页面无法隐藏密钥，请勿填入高额度或共享密钥。浏览器直连还受服务商 CORS 限制，若提示跨域失败，换用支持浏览器直连的服务商即可。
